## 화면 우선 구현 원칙

신규 기능은 화면과 역할별 내비게이션 플로우를 로컬 데이터로 먼저 검증한 뒤,
feature 계약과 Supabase repository를 연결한다. 프로토타입 단계에서는 서버 저장,
실제 이메일 발송, 운영 알림이 실행된 것처럼 표시하지 않는다.

현재 구현된 플로우:

- 고객 이메일 회원가입 → 이메일 확인 안내 → 고객 로그인 → 고객 탭
- 운영자가 생성한 관리자 계정 로그인 → 관리자 운영 홈 → 로그아웃
- 업체 담당자 로그인과 역할 화면은 미구현
- 관리자 요청 선택 → 업체 선택 → 소속 담당자 지정 → 배정 내용 검토는 계획 상태
